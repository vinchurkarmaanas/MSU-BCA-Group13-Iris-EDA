## Project Overview
This repository contains the dataset files and Python source code for our Exploratory Data Analysis (EDA) on the UCI Iris Plants Database.

## Repository Contents
* `bezdekIris.data` — Corrected 150-instance dataset (resolves transcription errors in rows 35 and 38).
* `iris.data` — Original UCI 150-instance dataset.
* `iris.names` — Official dataset metadata, summary statistics, and attribute documentation.
* `Index` — UCI repository directory index.
* `iris_eda_group13.py` — Complete Python script for data quality auditing, descriptive statistics, species aggregation, correlation matrices, and visualization generation.
